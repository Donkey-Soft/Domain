Natural Text Shortcuts

Create short triggers for words or text you type often. Natural Text Shortcuts expands them across many Windows desktop apps, with matching and settings kept on your device.

Windows 10 and 11 Portable, per-user app Free for personal and commercial use after release x64 validated ARM64 not runtime-validated

Local data

Natural Text Shortcuts has no network client or telemetry. For matching, it keeps a short in-memory suffix bounded by configured triggers. While the app runs, configured shortcuts and expansion text are also held in process memory. Settings and backups use Windows DPAPI for the current user. Exports are readable JSON files.

Trigger choices

Immediate mode expands on the final trigger character. Boundary mode waits for Space, Enter, or Tab. Each trigger can keep the typed sequence, replace it with the expansion, or remove it without inserting text.

Made for Windows

The portable app needs no installer or admin rights for ordinary use. It starts with its settings window and stays available from the notification area when minimized or closed.

How settings are protected

Natural Text Shortcuts encrypts its settings file and automatic backup on disk with the Windows Data Protection API (DPAPI) in CurrentUser mode. The files live under %LOCALAPPDATA%\NaturalTextShortcuts\, and their protection is tied to the current Windows user profile. They are not portable to another account.

Encryption protects saved files, not data while Natural Text Shortcuts is running. Configured shortcuts and expansion text remain in process memory, and DPAPI does not protect against the signed-in user, malware running as that user, or memory inspection. Profile loss or account changes can make settings unrecoverable. Exports are readable JSON and should be protected separately.

How text expansion works

Natural Text Shortcuts uses a Windows low-level keyboard hook to match configured triggers, then inserts the expansion with Windows Unicode input events. The matching buffer is limited to the length needed for configured triggers. Startup is off by default and can be enabled from settings.

Input behavior depends on the target app and Windows security context. Natural Text Shortcuts may not work in secure desktops, protected fields, some remote sessions, elevated windows when the app runs unelevated, or apps that reject simulated input.

For managed Windows environments

IT teams can package the prepared app folder as a Win32 .intunewin package and deploy it through Microsoft Intune to users. Natural Text Shortcuts installs per user; it does not include machine-wide installation or managed policy controls. Organizations should review their application-control policies before rollout.
